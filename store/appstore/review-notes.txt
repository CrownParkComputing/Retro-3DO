Retro-3DO is an independently written 3DO emulator. This iOS release uses a native SwiftUI library, Files importer, Settings, guided setup and touch-control editor. The setup guide opens on first launch and can be reopened from Settings > How Retro-3DO works. Arrange my controls opens the layout editor without starting a game, including when a hardware controller is connected. To review without supplying any content: select the demonstration tile, or choose Play the demo now in the guide. The original demonstration ROM was written for this app, exercises video/audio/controller input and needs no commercial BIOS or game. Touch controls and supported Bluetooth controllers work in the demo. Commercial system ROMs and games are not bundled, downloaded or sold; users import their own files with the + tile. Imported BIOS choices, pad layouts, library entries and shared saved RAM persist between launches. No account or sign-in is required.
