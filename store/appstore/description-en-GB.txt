Retro-3DO brings the 3DO Interactive Multiplayer to iPhone and iPad, with a native game library and guided setup.

TRY THE INCLUDED DEMO

Start with the original demonstration written by Crown Park Computing. It works immediately, with no system ROM or disc required. Move the marker with the directional controls and change its colour with A, B and C while the emulator runs its video, sound and controller hardware.

ADD YOUR OWN DISCS

Use the + tile to import a 3DO disc image or system ROM through Files. Imported files are copied into the app so your library stays available after the original moves. The app recognises system ROMs and keeps them separate from game tiles.

The setup guide takes you through importing content, using a controller and arranging the on-screen pad. Reopen it whenever you need it from Settings.

MAKE THE CONTROLS YOURS

Play with touch controls or a supported game controller. Arrange the on-screen controls from the guide or Settings, including while a controller is connected. Your layout is remembered.

KEEP YOUR PROGRESS

The console's saved RAM is shared across your games and saved automatically. Existing saved RAM is preserved when updating the app.

THE 3DO HARDWARE

Retro-3DO emulates the ARM60 processor, MADAM and CLIO graphics hardware, DSPP audio, controller input and CD media, including CHD images. Emulation and screen presentation run separately.
